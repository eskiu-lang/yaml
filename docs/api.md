## `<yaml>`

Reads YAML configuration files into the standard library's JSON tree.

```eskiu
YamlError err;
*JsonValue cfg = yaml_load("config.yaml", &err);
if (cfg == null) {
    printf("config.yaml:%d:%d: %s\n", err.line, err.col, err.message.cstr());
    return 1;
}
defer JsonValue_free(cfg);
*JsonValue port = json_get(cfg, "server.port");
```

The result is a `<json>` JsonValue, so json_get paths, JsonValue_get/at and
JsonValue_stringify work on it. One document is read, with the YAML 1.2 core schema:
block mappings and sequences (also a sequence at the same indentation as its key),
flow collections ([a, b], {a: 1}), plain, single-quoted and double-quoted scalars
(folded over several lines, every escape), literal and folded block scalars (|, >, with
chomping and indentation indicators), comments, and the --- and ... markers. A plain
scalar is null (null, Null, NULL, ~ or nothing), a boolean (true, True, TRUE, false,
...), an integer (decimal, 0x hex, 0o octal), a float (1.5, 1e3, .inf, -.inf, .nan), or
else a string; a quoted or block scalar is always a string. Numbers are doubles, as in
`<json>`, so an integer past 2^53 loses precision. Keys are strings: `1: a` has the key
"1". A duplicate key is an error.

Left out, each a located error: anchors and aliases (&a, *a), tags (!x), complex keys
(? ), directives (%YAML), several documents in one stream, and a key: value pair inside
a flow sequence. Tabs may separate tokens but not indent.

### YAML_MAX_DEPTH

```eskiu
const int YAML_MAX_DEPTH = 512;
```

The deepest nesting of collections the parser accepts; deeper input is an error.

### YamlError

```eskiu
struct YamlError {
    int line;
    int col;
    String message;
}
```

Where and why a parse failed: line and col count from 1 (col in bytes), message says
what was wrong. Free it with YamlError_free.

### YamlError_free

```eskiu
void YamlError_free(YamlError* self)
```

Frees the message.


## `<yaml/yaml_node>`

Maps, sequences and the entry points (part of yaml.esk, which imports it in order after the ones before it)

### yaml_parse_bytes

```eskiu
*JsonValue yaml_parse_bytes(*char text, int64 len, YamlError* err)
```

Parses the YAML document in the len bytes at text. Returns the value (free it with
JsonValue_free), or null on an error, which is described in *err (err may be null). An
empty document is a JSON null. CRLF line ends and a UTF-8 byte order mark are accepted.

### yaml_parse

```eskiu
*JsonValue yaml_parse(string text, YamlError* err)
```

Parses a NUL-terminated YAML document; see yaml_parse_bytes.

### yaml_load

```eskiu
*JsonValue yaml_load(string path, YamlError* err)
```

Reads and parses the YAML file at path; see yaml_parse_bytes. A file that cannot be read
is an error at line 0.
